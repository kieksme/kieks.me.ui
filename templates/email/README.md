# MJML-Anschluss

Die gerade entstehenden Abschlussvorlagen verbleiben vorerst unter `kieks.me.datahub/templates/email`. Nach Stabilisierung können Darstellung und Compiler hierher übernommen werden; Versand, Empfänger, Ergebnisprüfung und Berechtigungen bleiben im DataHub. Gemeinsame Tokens beim Build als konkrete Farben einsetzen, Dark-Mode-Regeln pro Mailclient separat liefern und Textalternativen erhalten. Noch keine Mailvorlagen in diesem Starter implementiert.
