# Geplanter Astro-Adapter

Noch kein installierbares Paket. Ausgangspunkt sind Website-Atoms (Logo, Heading, Lead), Molecules (Karten, FaqItem) und später Organisms. Vor Übernahme Abhängigkeiten, vorhandene CSS-Klassen, Assets und Props inventarisieren. Astro 5/7 und Tailwind 3/4 benötigen Konsumententests; Quellkomponenten aus einem beliebigen Nachbarcheckout zu importieren ist kein Releaseverfahren.
