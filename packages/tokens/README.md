# @kieksme/kieksme-tokens

Framework-independent kieks.me CSS variables and JSON values, extracted from the existing website. Explicit light mode: `[data-theme="light"]`; dark mode: `.dark` or `[data-theme="dark"]`.

```js
import '@kieksme/kieksme-tokens/css';
```

JSON export: `@kieksme/kieksme-tokens` or `@kieksme/kieksme-tokens/tokens.json` (Node JSON imports require the appropriate import attribute). This package does not load fonts, assets or global utility-framework styles. Fonts: Hanken Grotesk (headings), Source Sans 3 (body); load separately with their licenses.

See LICENSES.md for provenance. No registry release has been performed by the initial packaging preparation.
